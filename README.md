## How to read this

Start with whichever week interests you — each README is self-contained. If you only
read one, [Week 1](./Week-1/README.md) sets up the lens the rest of the cohort builds
on: *map the system, not the model.*

Some weeks also have a companion Medium article that expands the write-up into prose,
and a LinkedIn post — linked from inside each week's README where they exist.

---

## Frameworks I keep returning to

- [MITRE ATLAS](https://atlas.mitre.org/) — the adversarial-ML threat knowledge base
  (*how do attackers actually hit AI?*).
- [OWASP Top 10 for LLM Applications](https://genai.owasp.org/) — the field's shared
  defenders' checklist (*how do we build safely?*).
- STRIDE — classic threat taxonomy, mapped onto AI systems (*what kind of threat is this?*).
